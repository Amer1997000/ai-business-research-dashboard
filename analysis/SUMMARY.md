# Analysis summary

> **70-participant experiment simulation — portfolio demonstration. These are synthetic observations, not recruited-human evidence.**

## Verified counts

- 70 completed simulated sessions
- 560 task responses
- 70 feedback submissions
- 35 manual-first and 35 AI-first
